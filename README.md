# Confused2Career
Confused2Career is an AI-powered career guidance platform that helps students navigate their journey from confusion to career readiness.

Many students struggle to choose the right career path and prepare systematically for internships and placements because learning resources are scattered across multiple platforms.

The platform begins by asking the student three simple questions: 
their placement date, the number of hours they can study each day, and their dream company. Based on these inputs, Confused2Career generates a personalized career preparation plan.

The system provides four core features:
1. Roadmap – Generates a personalized step-by-step learning roadmap and task listing based on the student's goals and timeline.
2. ATS-Friendly Resume Update – Creates and continuously updates a resume optimized for Applicant Tracking Systems (ATS).
3. Skill Dashboard – Evaluates and rates the student's skills while tracking overall preparation progress.
4. Recommendation System – Recommends relevant courses and learning resources from platforms such as Coursera, Udemy, NPTEL, LeetCode, and GeeksforGeeks according to the student's skill gaps.
